# 单体审查终稿复盘

本复盘来自一次经审查者修正并最终确认的单体审查意见，用于校正skill的覆盖、判断和表达习惯。

## 差异结果

- AI原稿9条，终稿18条；6条保留但压缩措辞，3条删除，12条新增。
- 删除项包括两类偏文件管理的图签/目录问题，以及一条只凭局部门扇符号形成的开启方向判断。
- 新增项覆盖屋面板厚度、防水层数、消防平面参数、儿童活动场所、太阳能系统、剖面表达、露台防护、楼梯和墙身详图索引、重复编号、栏杆高度及防水收口。
- 原稿18张证据图支撑9条意见；终稿20张支撑18条意见，说明证据应精准而非堆叠。单一位置通常一张，跨图矛盾才需要多张。

## 固化规则

1. 不得在设计说明和少量平面发现问题后停止；每张图纸必须关闭覆盖状态。
2. 正式意见定位优先写图号和图名，PDF页码只作为证据辅助位置。
3. 文字采用“明确事实—适用要求或内部矛盾—具体修改动作”，不扩写证据无法支持的推测。
4. 图纸内部矛盾、索引编号和表达完整性问题可以受控填写 `法规条文：无`；技术阈值、强制性和政策结论必须引用规范。
5. 图形方向或符号语义未闭合时不得定案，降级为 `needs_review`。
6. 只接受既定12类意见类型；终稿中的偶发文字笔误不形成新枚举。
7. 单体v1.2报告默认使用 `建筑单体施工图内审意见` 及确认后的章节样式。

## 第二次终稿复盘：匿名体育馆单体

一次体育馆单体复盘对比了首次技术审查、补充意见整理稿和审查者终稿。首次技术审查只有4条，终稿为21条；终稿中仅2条可追溯到首次审查的核心问题，另19条来自后续逐图补充。首次工作区虽然把全部图纸标成 `reviewed`，但多项检查只写“已提供无障碍专篇”“防水专篇和大样已提供”“看台大样已提供”或“大样覆盖完整”，导致表面覆盖完整而实质漏审。

本次复盘固化以下经验：

1. 图纸覆盖率不是 `review_status` 的行数统计。每张图纸必须由图号/图名、该图事实和实质检查项共同闭环。
2. 无障碍出入口、无障碍电梯和卫生间不能用“已有专篇”关闭；应分别核对平台、通行与提示、服务设施及详图参数。
3. 防水与屋面不能用“已有防水专篇/墙身大样”关闭；应核对坡向、雨水口或地漏、滴水、上翻、收头及材料层次。
4. 楼梯、栏杆和看台不能用“已有大样”关闭；应核对净宽净高、防护高度与荷载、看台视线和索引闭合。
5. 目录和缺图问题必须核对目录、PDF实际页及图签。一次合并列出多张疑似缺图的意见，终稿只保留了能够确认的一张，说明不确定范围必须留在 `needs_review`。
6. 一条意见只保留一个根因和整改动作。适用条件未闭合的消防或其他技术判断不得进入 `verified`。
