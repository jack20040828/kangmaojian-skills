# 建筑总图施工图审查意见 格式说明

_来源：老板发的永州零陵机场油库迁建工程建筑总图施工图审查意见范本逆向总结_
_更新日期：2026-04-21_

## 一、封面格式

| 位置 | 字体 | 字号 | 加粗 | 对齐 |
|------|------|------|------|------|
| 项目名称 | 黑体 | 小二18pt | ✅ | 居中 |
| 书名（审查意见） | 黑体 | 小二18pt | ✅ | 居中 |
| 日期 | 宋体 | 12pt | ❌ | 居中 |

**格式（三行独立）：**
```
永州零陵机场油库迁建工程房建项目
建筑总图施工图审查意见
2026年4月18日
```

- 第一行：项目名称（黑体小二加粗居中）
- 第二行：书名"建筑总图施工图审查意见"（黑体小二加粗居中）
- 第三行：日期（宋体12pt不加粗居中）
- **无"审查人"行**

## 二、章节标题（一级标题）

总图审查意见的章节标题与单体不同：

```
总图（建筑）施工图设计说明：
总图设计图纸：
```

| 属性 | 值 |
|------|------|
| 字体 | 黑体 |
| 字号 | 小四14pt |
| 加粗 | ✅ |
| 对齐 | 左对齐 |
| 编号 | 不编号，直接写章节名 |

**典型章节结构（根据范本总结）：**
1. `总图（建筑）施工图设计说明：` — 涵盖ZS-01、ZS-02设计说明的审查意见
2. `总图设计图纸：` — 涵盖ZS-03总平面布置图的审查意见

## 三、每条审查意见格式（核心规则）

### 标准格式
```
1、涉及图纸：图名【XXX】，图号【XXX】。
  【审查意见】：[问题描述正文，精准描述问题所在，加粗]截图如下：[或 截图同【审查意见X】]
  [截图，红框标注问题位置]
  【法规条文】：《规范全名》第X.X.X条规定。（无条文时写"无。"）
  【意见类型】：[类型]，[必须/建议]修改（[方向]）。
```

### 逐项说明

#### 涉及图纸行
```
涉及图纸：图名【总图（建筑）施工图设计说明二】，图号【ZS-02】。
```

- **格式要素**：`涉及图纸：` → `图名` → 方括号【】 → `图号` → 方括号【】
- **字体**：宋体12pt，**不加粗**
- **标点**：图名和图号之间用逗号分隔

#### 审查意见行
```
【审查意见】：八、无障碍设计-2、无障碍实施范围-"（8）无障碍停车位按不小于总车位的1%计算，项目共设置无障碍停车位2个，具体布置详总平面图。"与本项目总图设计设置1个无障碍停车位不符。截图如下：
```

- **标签"【审查意见】"**：宋体12pt，中文方括号，**不加粗**
- **正文描述**：宋体12pt，**加粗**
- **截图标注**：正文末尾写"截图如下："（宋体12pt，不加粗）
- 多条意见引用同一张截图时，写"截图同【审查意见X】"

#### 法规条文行
```
【法规条文】：《建筑工程设计文件编制深度规定》（2016年版）第4.2.3条规定。
```

- **标签不加粗**，条文内容**不加粗**
- 规范名称用全称（如《建筑工程设计文件编制深度规定》），不用缩写
- **无条文时写"无。"**，不能用"无条文"或省略

#### 意见类型行
```
【意见类型】：设计深度，必须修改（其它）。
```

- **标签不加粗**，类型内容**不加粗**
- 标注必须准确，对应12种类型之一

## 四、截图要求（核心规则，必须严格遵守）

### 4.1 截图三大原则（按重要性排序）

**原则1：图文对应优先**
- 先写审查意见文字 → 明确说的是哪个问题点 → 再决定截哪张图纸的哪个区域
- 截图内容必须和文字意见描述的问题点完全匹配
- 写完意见后必须复核：文字→图纸位置→截图，三者是否一致

**原则2：截图范围宁大勿小**
- 截图要能看出问题点在哪里，包含问题点及其周边有定位意义的参照物
- 轴线至少露出一两条，尺寸线能辅助定位
- 避免只截问题点本身而不留周边参照

**原则3：红框只框问题点**
- 红框要框的是审查意见文字中描述的那个**具体错误所在**
- **不是框房间名称**（如"门房"两个字）
- **不是框整张截图的外围**
- 是框：那个具体的错误所在（如：某个数字标注、某条条款、某个标高符号）
- 红框宁小勿大，只框住问题点，线条细而醒目

### 4.2 范本截图分析（5张）

| 截图编号 | 对应意见内容 | 红框框住的内容 |
|---------|-------------|--------------|
| ex_shot_00 | 生产值班用房与门房/变电站间距未标注 | 红框框住门房+变电站区域；红框框住无障碍车位标注 |
| ex_shot_01 | 无障碍停车位2个vs图上1个不符 | 红框框住ZS-02中第(8)条关于无障碍停车位设置的完整条款 |
| ex_shot_02 | 主要技术经济指标表缺停车位数量 | 红框框住主要技术经济指标表（表示缺失内容） |
| ex_shot_03 | 基地内道路与城市道路连接处未设限速设施 | 红框框住门房+变电站区域（含坐标标注） |
| ex_shot_04 | 风玫瑰旋转角度超过45° | 红框框住风玫瑰图 |

**关键观察：**
- 红框都是**精准框住问题点**，不是框房间名称文字，不是框整张截图
- 截图都包含**周边定位参照物**（坐标、轴线、尺寸线、建筑名称等）

### 4.3 截图正面规则（应该这样做）

- 截图范围：包含问题点 + 至少一条轴线或尺寸线用于定位
- 截图内容：问题所在的具体位置，周边有参照物
- 红框位置：精准框住审查意见文字描述的那个错误点
- 截图质量：高清晰度，CAD线条和文字清晰可辨
- 构图干净：无截图工具UI元素，无大面积无意义白边
- 如涉及多个问题点：应分截或多框，不能一个截图试图说明所有问题

### 4.4 截图避免问题（绝对禁止）

| 错误类型 | 具体表现 |
|---------|---------|
| ❌ **整个截图加红框** | 在整个截图外围加一圈红框（这是严重错误） |
| ❌ 文不对题 | 意见说A问题，截图截到B内容 |
| ❌ 红框位置漂移 | 红框框了与意见描述无关的位置（如框到墙上、隔墙上、框住房间名称文字） |
| ❌ 截图范围太小 | 只截到问题点一小部分，无定位参照 |
| ❌ 截图范围太大 | 把整张平面图截进来，问题点被压缩到看不清 |
| ❌ 偏到图框边缘 | 问题区域只占截图一小块 |
| ❌ 截错图纸位置 | 截到无关内容 |
| ❌ 截图不干净 | 带着截图工具UI元素（灰色边框、圆形调节节点、工具栏） |

### 4.5 截图复核流程（每条必须执行）

写完意见后按此顺序复核，全部YES才能输出：
1. 文字说的是哪个问题？
2. 在哪张图纸的哪个位置？
3. 截图截的是不是同一个位置？
4. **红框框的是不是文字说的那个错误点？**（不是框房间名称，不是框整张图，是框那个具体的错误点）

### 4.6 截图引用

当多条意见引用同一张截图时：
```
截图同【审查意见3】
```
表示这张截图与"审查意见3"是同一张，不用重复贴。

## 五、注脚格式

末尾一段：
```
注：【意见类型】包含消防安全强制性条文、一般性条文、政策规定、设计深度与必须修改（消防安全）组合4种类型，其它强制性条、一般性条文、政策规定、设计深度与必须修改（其它）、建议修改（其它）的两两组合共8种类型，共12种意见类型。
```

- **字体**：宋体12pt，**加粗**（或黑体12pt加粗）
- 一行写完不断行

## 七、总图与单体审查意见的区分

| 维度 | 建筑总图审查意见 | 建筑单体审查意见 |
|------|---------------|----------------|
| 章节结构 | 总图（建筑）施工图设计说明 / 总图设计图纸 | 设计说明 / 平面图 / 立面剖面图 / 大样图 |
| 图号类型 | ZS-01、ZS-02、ZS-03等总图号 | A-01、A-02等建筑单体图号 |
| 截图特点 | 常截总平面图局部（指标表、风玫瑰、无障碍流线） | 常截平面图局部（卫生间、楼梯间、门窗洞口） |
| 常见问题 | 防火间距、指标矛盾、风玫瑰、竖向设计 | 疏散距离、防水做法、无障碍厕位、净高不足 |
| 规范依据 | 总图制图标准、民用建筑通规、建筑设计防火规范 | 住宅设计规范、无障碍设计规范、建筑面积计算规范 |
