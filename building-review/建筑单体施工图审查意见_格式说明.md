# 报告样本格式说明

## 一、封面格式

```
永州零陵机场油库迁建工程房建项目（黑体，小二18pt，加粗，居中）
生产值班用房建筑单体施工图内审意见（黑体，小二18pt，加粗，居中）
2026年4月18日（宋体，12pt，不加粗，居中）
```

- 项目名称、子项名称+书名、日期，三行
- 黑体小二（18pt）加粗做标题
- 宋体12pt做日期，不加粗
- **无"审查人"行**

---

## 二、一级标题（章节）

```
设计说明：（黑体，小四14pt，加粗）
二、平面图：（黑体，小四14pt，加粗）
三、立面、剖面图：（黑体，小四14pt，加粗）
四、大样图：（黑体，小四14pt，加粗）
```

- 中文数字编号（一、二、三、四）+ 顿号 + 章节名 + 冒号
- 四个章节统一：黑体小四（14pt）加粗

---

## 三、每条审查意见格式

```
1、涉及图纸：图名【XXX】，图号【XXX】。
  【审查意见】：[问题描述正文，加粗]截图如下：[或 截图同【审查意见X】]
  [截图，红框标注问题位置]
  【法规条文】：《规范全名》第X.X.X条规定。（无条文时写"无"）
  【意见类型】：[类型]，[必须/建议]修改（[方向]）。
```

**编号：** 阿拉伯数字+顿号（1、2、3…），贯穿全文不重置

**标签都不加粗：**
- "涉及图纸" — 不加粗
- "【审查意见】" — 不加粗（中文方括号【】本身有视觉重量）
- "【法规条文】" — 不加粗
- "【意见类型】" — 不加粗

**正文加粗：**
- "【审查意见】"后的问题描述正文 — 加粗

**法规条文格式：**
- 用规范**全称**：《建筑节能与可再生能源利用通用规范》第3.1.5-1条
- 不用缩写：如"GB55015-2021"

---

## 四、截图要求（核心规则，必须严格遵守）

截图必须遵循三大原则：

### 4.1 截图三大原则（按重要性排序）

**原则1：图文对应优先**
- 先写审查意见文字 → 明确说的是哪个问题点 → 再决定截哪张图纸的哪个区域
- 截图内容必须和文字意见描述的问题点完全匹配
- 写完意见后必须复核：文字→图纸位置→截图，三者是否一致

**原则2：截图范围宁大勿小**
- 截图要能看出问题点在哪里，包含问题点及其周边有定位意义的参照物
- 轴线至少露出一两条，尺寸线能辅助定位
- 避免只截问题点本身而不留周边参照

**原则3：红框只框问题点**
- 红框要框的是审查意见文字中描述的那个具体错误所在
- 不是框房间名称（如"无障碍卫生间"五个字）
- 不是框房间（如整个卫生间区域）
- 是框：那个具体的错误所在（如：某个勾选项、某个门编号、某个标高缺失处）
- 红框宁小勿大，只框住问题点，线条细而醒目

### 4.2 截图正面规则（应该这样做）

- 截图范围：包含问题点 + 至少一条轴线或尺寸线用于定位
- 截图内容：问题所在的具体位置，周边有参照物
- 红框位置：精准框住审查意见文字描述的那个错误点
- 截图质量：高清晰度，CAD线条和文字清晰可辨
- 构图干净：无截图工具UI元素，无大面积无意义白边
- 如涉及多个问题点：应分截或多框，不能一个截图试图说明所有问题

### 4.3 截图避免问题（绝对禁止）

- ❌ 文不对题：意见说A问题，截图截到B内容
  - 例：意见说"防水做法不一致"，截图截到卫生间平面图
  - 例：意见说"未设外遮阳"，截图截到外墙外保温内容
- ❌ 红框位置漂移：红框框了与意见描述无关的位置
  - 例：意见说"配电间门为FM乙1523"，红框框到了墙上
  - 例：意见说"缺少图名"，红框框住了房间名称文字
- ❌ 截图范围太小：只截到问题点的一小部分，无定位参照
  - 例：遮阳问题只截一个小窗，看不到东/南/西/北朝向
- ❌ 截图范围太大：把整层平面图截进来，问题点被压缩到看不清
- ❌ 偏到图框边缘：截到图框边缘（指北针+尺寸线），问题区域只占一小块
- ❌ 截错图纸位置：防水勾选问题截到设计依据规范列表
- ❌ 截图不干净：带着截图工具的UI元素（灰色边框、圆形调节节点、工具栏）

### 4.4 截图复核流程（每条必须执行）

写完意见后按此顺序复核，全部YES才能输出：
1. 文字说的是哪个问题？
2. 在哪张图纸的哪个位置？
3. 截图截的是不是同一个位置？
4. 红框框的是不是文字说的那个错误点？

### 4.5 截图引用

当多条意见引用同一张截图时：
```
截图同【审查意见14】
```
表示这张截图与"审查意见14"是同一张，不用重复贴。

### 4.5 哪些意见需要截图

- 问题能通过图示说明更清楚的
- 需要指出具体位置（轴线、格子、标注）的
- 纯文字就能说清的，可不贴图但须有"截图如下："标注

**核心原则**：截图是**精准证据**，不是示意图。框住什么就说明什么，不截无关内容。

## 五、意见类型标注

格式：`[类型]，[必须/建议]修改（[方向]）`

示例：
- 设计深度，必须修改（其它）
- 其它强制性条文，必须修改（其它）
- 一般性条文，必须修改（消防安全）
- 建筑设计防火规范（2018年版）第6.2.7条

---

## 六、注脚格式

一句话，不逐条列：

```
注：【意见类型】包含消防安全强制性条文、一般性条文、政策规定、设计深度与必须修改（消防安全）组合4种类型，其它强制性条文、一般性条文、政策规定、设计深度与必须修改（其它）、建议修改（其它）的两两组合共8种类型，共12种意见类型。
```

- 黑体，12pt，加粗
- 一行写完不断行
